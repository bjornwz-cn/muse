# 蓝牙耳机智能助手 App — 方案规格（草稿）

> 状态：需求问答中。v0.1，2026-11-07 由王震口述、muse 整理。
> 定位：Android App，常驻后台，把普通蓝牙耳机变成「通知播报员 + 随身同传」。

## 一句话定义

连接普通蓝牙耳机后，App 在后台常驻运行，实现两件事：
1. 手机通知按规则实时语音播报到耳机；
2. 外部语音实时翻译（如英语 → 普通话）并播报到耳机。

## 已定决策（2026-11-07 第一轮问答）

| # | 议题 | 定案 |
|---|---|---|
| 平台 | 目标系统 | Android（用户手机：荣耀 HONOR BVL-AN00）；iOS 因后台/通知权限限制不做 |
| Q1 | 翻译输入源 | C：面对面收音（一期）+ 手机内声音，如视频/会议（二期），两者都要 |
| Q2 | 翻译模式 | A：准同传，流式边说边译，目标延迟 1~3 秒，接受少量半句修正 |

| Q4 | 通知播报规则 | 可配置规则引擎：按应用列表、按时间段、重点白名单，用户自由组合选择 |

## 功能模块

### 1. 蓝牙连接管理
- 耳机连接状态监测、断开自动重连提示
- 音频路由：播报/翻译音频走蓝牙耳机；与来电、音乐的冲突仲裁（见待定 Q6）
- 普通蓝牙耳机即可（A2DP/HFP），不依赖耳机智能功能

### 2. 通知播报
- NotificationListenerService 读取通知
- 规则引擎：App 维度开关、时间段（如工作时间/夜间静默）、重点联系人/应用白名单
- TTS 播报，语速/音量可调
- 播报与媒体混音同步出声，不申请音频焦点、不压低媒体音（v0.8.7）；v0.8.8 起“播报时降低媒体音量”做成功能开关（默认关），开时申请 MAY_DUCK 焦点压低媒体音，全程记日志 + 看门狗兜底防泄漏
- 前台服务常驻 + 国产系统保活（电量白名单引导，荣耀/华为系重点适配）

### 3. 实时翻译（一期：面对面）
- 手机麦克风收音 → 流式 ASR → 流式翻译 → TTS 播入耳机
- 目标端到端延迟 1~3 秒
- 云端引擎为主、离线引擎兜底（待定服务商，见 Q8）

### 4. 实时翻译（二期：手机内声音）
- 捕获手机内部音频（视频、线上会议）做同上流水线

## 技术要点/风险
- 后台保活是国产安卓头号难点：前台服务 + 电量优化白名单 + 厂商自启引导
- 同传延迟取决于 ASR 流式分句与翻译增量输出策略
- 嘈杂环境收音质量：依赖手机麦克风指向与降噪，必要时支持外接领夹麦（后续）
- 开发交付：muse 在云端写代码并编译 APK，王震自行安装到手机实测迭代（muse 不能远程装应用）

## GitHub 调研结论（2026-11-07）

### 高度同类：EyeOpener-Translator（翻译半边）
- zt-Fang/EyeOpener-Translator，Apache-2.0，2026-06 建仓、持续更新、有 Release APK。
- 已实现：Android 悬浮字幕（任意 App 之上）、麦克风 + 设备内部音频双路捕获、端侧流式 ASR（sherpa-onnx/Vosk，41 语种，含中英混说）、翻译三档引擎可切换（本地离线 / 自备 Key 云端 / 大模型）、历史记录本地保存、按键加密存储、无账号无埋点。
- 与本方案的重合：Q1 输入源、Q7 悬浮窗、Q8 引擎可插拔、Q10 字幕+记录，几乎全中。
- 它没有的（正是本项目要自研的）：译文 TTS 语音播报入耳机、通知播报、蓝牙连接管理、中→外语音外放。
- 定案：**不从零写翻译层**。以其技术路线为基线（sherpa-onnx 流式 ASR + 可插拔翻译引擎 + 悬浮层），fork 改造或同架构自研，二选一在 M2 启动时按代码质量复核后决定；许可证 Apache-2.0 允许改造与内部使用。

### 参考：Sokuji（kizuna-ai-lab/sokuji，★1478）
- 桌面/Web 双向实时语音翻译（会议场景），流式管线设计可借鉴，非 Android，不直接复用。

### 通知播报半边
- GitHub 无成熟开源实现（仅 ★0~1 的小项目）；但 NotificationListenerService + 系统 TTS 是安卓标准能力，商业产品（Audify 等）已验证形态。自研，工作量可控。

### 核心组件选型
- 端侧 ASR/TTS：sherpa-onnx（Apache-2.0，流式识别 + 中文合成）；VAD：Silero VAD（MIT）
- 云端引擎：适配器接口，免费额度起步（ASR/翻译各家可换，设置内填 Key）
- 语言：Kotlin + 前台服务 + NotificationListenerService
